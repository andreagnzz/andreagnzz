## Work

**Orma** · 1st place, XRPL Lending Hackathon, Paris 2026\
Solvency oracle for closed-ended XRPL lending vaults. A vault's first recognised loss is invisible to indexers that diff transaction metadata, so it can read 1.00 while holding 0.80. Orma reads the ledger objects instead, publishes each grade as a native XLS-47 oracle object and gates subscriptions with XLS-70 credentials. Shipped with a protocol paper and a 40-finding developer-experience report.\
[Repository](https://github.com/BuzzBallz/orma) · [Live](https://ormaprotocol.vercel.app) · built with [Alexandre Lemiere](https://github.com/frytegg)

**AgentFi** · two prizes, ETHDenver 2026\
Multi-chain marketplace for autonomous AI agents: iNFTs (ERC-7857) on 0G, x402 agent-to-agent payments, micropayments on ADI Chain and execution proofs on Hedera.\
[Repository](https://github.com/BuzzBallz/agentfi) · [Live](https://agentfi-frontend.vercel.app) · [Devfolio](https://devfolio.co/projects/agentfi-3428) · built with [Alexandre Lemiere](https://github.com/frytegg)
